### 📜 3. Complete 114 Surahs & Offline Reading
- Complete catalog of all 114 Surahs with both Meccan (مكية) and Medinan (مدنية) designations.
- Verse-by-verse Arabic text, English transliteration, Sahih International translation, and Urdu translation.
- Adjustable Arabic and translation font scaling with immediate live preview.
- Quick Jump to any Ayah or Surah.

### 🎨 4. Interactive Rules of Tajweed
Interactive guide and verse breakdown for the core science of Tajweed:
- **Ghunnah (غنة)**: Nasalization on Noon and Meem Mushaddadah (2 Harakat).
- **Idgham (إدغام)**: Assimilation with/without ghunnah.
- **Ikhfa (إخفاء)**: Concealment of Noon Sakinah/Tanween.
- **Qalqalah (قلقلة)**: Echoing on قطب جد.
- **Iqlab (إقلاب)**: Conversion of Noon to Meem before Baa.
- **Madd (مد)**: Lengthening (Asli, Muttasil, Munfasil, Lazim).
- **Izhar (إظهار)**: Clear throat letters pronunciation.

### 🧠 5. Hifz Memorization Studio & Progress Tracking
- **Ayah Masking / Card Recall**: Tap to reveal the Arabic text to test memorization.
- **Audio Repetition Looper**: Set Ayah loop counts to 1x, 3x, 5x, 10x, or 20x for effortless retention.
- **Next Ayah Quiz**: Test recall by identifying the following verse in sequence.
- **Three-Tier Status**: Mark verses as *Not Started*, *In Progress*, or *Mastered*.
- **Daily Target & Streak Tracker**: Keep track of daily Ayah goals, memorization percentage, and streak continuity.
- **Bookmarking Engine**: Save favorite ayahs with quick one-touch recall.

## 🚀 Building & Running the Project

### Prerequisites
- Android Studio Hedgehog | 2023.1.1 or higher
- Android SDK Platform 36 (Minimum SDK: 24)
- JDK 17 / 21
- Gradle 8.11+

### Build Debug APK
```bash
gradle assembleDebug
```
The compiled APK will be generated at:
```
app/build/outputs/apk/debug/app-debug.apk
```

### Run Unit Tests
```bash
gradle :app:testDebugUnitTest
```

---

## 📥 Installing the APK on Android Devices

1. Transfer or download `app-debug.apk` to your Android phone or tablet.
2. Tap the downloaded APK file in your notification bar or file manager.
3. If prompted, enable **"Install unknown apps"** for your browser or file manager in Android Settings.
4. Tap **Install** and launch **Al-Saif Quran**.
